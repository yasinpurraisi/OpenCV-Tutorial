
# OpenCV Tutorial

introduction of the basics of [OpenCV](https://opencv.org/) for image processing and computer vision in Python.

## Features

- Image I/O (read / write / display)
- Pixel access & manipulation
- Color conversions (BGR ↔ RGB, grayscale)
- Cropping & resizing
- Color spaces and histograms
- Drawing primitives (lines, rectangles, circles) and text overlay
- Arithmetic operations on images
- Gamma correction (linear & non-linear)
- Mouse events and interactive callbacks
- Trackbars / sliders for parameter tuning
- Video I/O (webcam, URL stream, screen-record, file)
- Thresholding (Binary, Otsu, Adaptive)
- Morphological transformations (erode, dilate, open, close)
- Connected components / contour analysis
- Alpha channel (working with PNG transparency)
- Bitwise operations and masks
- Creating transparent PNGs programmatically
- Drawing shapes: lines, rectangles, circles, ellipses, polylines, filled polygons
- Text rendering and bounding boxes for text
- Brightness / contrast (linear) and histogram analysis
- Histogram equalization and CLAHE for contrast enhancement
- Blurring and denoising (mean, Gaussian, median, bilateral, non-local means)
- Sharpening with kernels
- Edge detection (Sobel, Laplacian, Canny)
- Hough transforms (line and circle detection)
- Color filtering (HSV/LAB) and green-screen removal
- K-Means color clustering and HSV histograms
- Kernel design and removing horizontal/vertical lines from documents
- Approximation of contours (approxPolyDP), shape detection and text bounding boxes
